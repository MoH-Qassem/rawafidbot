# RAWAFED BOT — نظام الإدارة المالية لشركة روافد

بوت Telegram عربي لإدارة الصندوق والمصروفات والإيداعات والسحوبات والعهد والديون وطلبات المساهمات، مع قيود مزدوجة وتقارير Excel وتسجيل أعضاء تفاعلي داخل المجموعة.

## المتطلبات

- Windows 10+ (أو أي نظام يدعم Python)
- Python 3.11 أو أحدث
- توكن بوت من [@BotFather](https://t.me/BotFather)
- `CEO_TELEGRAM_ID` لمعرف المدير فقط (بقية الأعضاء يسجّلون عبر زر «تسجيل عضويتي»)

## التثبيت على Windows

```powershell
cd D:\rawafidbot
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
Copy-Item .env.example .env
```

عدّل ملف `.env`:

| المتغير | الوصف |
|---------|--------|
| `BOT_TOKEN` | توكن البوت من BotFather |
| `CEO_TELEGRAM_ID` | معرف تيليجرام للمدير |
| `MAX_MEMBERS` | الحد الأقصى (افتراضي 5) |
| `MEMBER_TELEGRAM_IDS` | اختياري/قديم — لا يُفضَّل للإنتاج |
| `DATABASE_URL` | مسار SQLite (الافتراضي `sqlite:///data/rawafed.db`) |
| `TIMEZONE` | المنطقة الزمنية للجدولة |

## إنشاء البوت عبر BotFather

1. أرسل `/newbot` إلى `@BotFather` وانسخ التوكن إلى `BOT_TOKEN`.
2. فعّل المجموعات: `/setjoingrouproups` → Enable.
3. **Group Privacy Mode (مهم لتفاعل «يا محاسب»)**:
   - الافتراضي: البوت يرى الأوامر و@mention والرد على رسائله فقط.
   - لقراءة رسائل مثل «يا محاسب، كم الرصيد؟» **بدون** منشن: أرسل `/setprivacy` → Disable، ثم أعد إضافة البوت للمجموعة إن لزم.
   - مع Privacy=Enable يبقى العمل عبر `@bot` أو الرد على رسالة البوت أو الأزرار/الأوامر.
4. لا تمنح صلاحيات إدارية إلا للحاجة؛ لاستقبال `chat_member` (انضمام/مغادرة) قد يلزم جعل البوت مشرفاً بصلاحية محدودة أو الاعتماد على أول رسالة من العضو.
5. لا تشغّل أكثر من نسخة Polling واحدة لنفس التوكن.

## التشغيل الأول داخل مجموعة روافد

1. أضف البوت إلى مجموعة الشركة (بدون صلاحيات إدارية زائدة).
2. الـ CEO ينفّذ `/setup` داخل المجموعة.
3. البوت يتحقق من هوية الـ CEO، يهيّئ إعدادات المجموعة، ويرسل رسالة الترحيب **مرة واحدة فقط**.
4. الأعضاء يضغطون «تسجيل عضويتي» أو يرسلون `/start` (الهوية من `from_user.id` فقط).
5. يكمل كل عضو الاسم والمسمى واللقب **داخل المجموعة** (لا يُمنح صلاحيات من اختيار المسمى).
6. بعد التسجيل يظهر `/start` القائمة الرئيسية (`MENU_VERSION` الحالية).
7. العمليات المالية تتم في المجموعة؛ الإشعارات حسب إعداد المجموعة.

أوامر مفيدة: `/setup` · `/status` · `/start` · `/cancel`

**تفعيل النسخة الجديدة:** أوقف أي `python main.py` قديم → شغّل نسخة واحدة من `venv` → أرسل `/start` لتحديث لوحة الأزرار المخزّنة في تيليجرام. راقب في الـ Logs: `BUILD_ID` و`MENU_VERSION`.

## المناصب والصلاحيات

المناصب الافتراضية: CEO، مدير مالي، محاسب، عضو مجلس إدارة.

- الجميع متساوون في العمليات المالية الافتراضية.
- إنشاء طلبات المساهمات + إدارة المناصب/الأعضاء/النسخ الاحتياطي: للـ CEO (أو من يُمنح الصلاحية صراحةً).
- الـ CEO لا يمكن سحب صلاحياته الأساسية عبر الإعدادات العادية.
- التحقق يتم في طبقة Services وليس بإخفاء الأزرار فقط.
- واجهة الإدارة: زر «🏢 إدارة المناصب والصلاحيات» للـ CEO.

## التشغيل

```powershell
cd D:\rawafidbot
venv\Scripts\activate
python main.py
```

لا تشغّل أكثر من عملية واحدة. إن ظهر `Polling already running (pid=…)` أوقف تلك العملية يدوياً أولاً.

## الاختبارات

تستخدم قاعدة منفصلة لكل اختبار (لا تلمس `data/rawafed.db`):

```powershell
pytest rawafed_bot/tests/ -q
```

## النسخ الاحتياطي والاستعادة

- من البوت: **الإعدادات → نسخ احتياطي** (يتطلب صلاحية).
- يدوياً:

```powershell
python -c "from rawafed_bot.services.backup_service import BackupService; print(BackupService.create_backup('manual'))"
```

الاستعادة: أوقف البوت ثم انسخ ملف النسخة فوق `data/rawafed.db` (أو استخدم `BackupService.restore_backup`).

## البنية

- `rawafed_bot/accounting` — محرك القيد المزدوج
- `rawafed_bot/services` — منطق الأعمال والصلاحيات والتسجيل
- `rawafed_bot/bot` — واجهة aiogram 3 (مجموعة + خاص)
- `rawafed_bot/reports` — تقارير Excel
- `rawafed_bot/scheduler` — تقارير مجدولة
- `data/` — قاعدة التشغيل (مستثناة من Git)

## الأمان

- لا ترفع `.env` أو قواعد بيانات حقيقية إلى Git.
- لا تشارك `BOT_TOKEN`.
- الهوية دائماً Telegram User ID وليس الاسم.
- السجلات المالية لا تُحذف؛ الإلغاء عبر قيد عكسي وسجل تدقيق.
